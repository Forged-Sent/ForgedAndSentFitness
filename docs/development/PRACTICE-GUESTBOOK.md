# Practice guestbook

This page is for your first practice change in [Your first contribution](FIRST-CONTRIBUTION.md). Add **one line** to the end of the list below, then follow the guide to commit it, publish your branch and open a **Draft** pull request.

Practice pull requests stay drafts and are not merged, so this list on `main` stays short. That is expected: the point is to try the whole path once (branch, edit, check, commit, publish, draft PR, CI) on a change that cannot break the app.
